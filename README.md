# Analyzing Motorcycle Part Sales

## Project Overview
An advanced SQL analysis exploring wholesale motorcycle part sales over time across multiple warehouse locations. This project derives actionable business insights regarding net revenue performance by product line, month, and warehouse.

## Business Objectives
- Calculate monthly wholesale net revenue by product line and warehouse.
- Filter and evaluate performance specifically for wholesale transactions during the summer months (June, August).
- Sort and rank net revenue metrics to identify top-performing warehouses and product lines.

## Technical Skills Demonstrated
- **PostgreSQL / SQL**
- **Conditional Logic (`CASE` Statements)**
- **Date & Time Extraction (`EXTRACT()`)**
- **Aggregate Functions (`SUM()`, `GROUP BY`)**
- **Multi-level Sorting (`ORDER BY`)**

## Files Included
- `motorcycle_sales_analysis.sql`: The primary SQL script containing the aggregation and revenue calculation queries.
